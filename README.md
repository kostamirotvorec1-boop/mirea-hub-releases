# MireaHub

Учебный планер для студентов РТУ МИРЭА на **Mac и iPhone**: расписание с отметками посещения,
дедлайны и файлы из СДО, баллы БРС с анализом «что нужно на оценку», напоминания о сроках
и отметка на паре по QR. Всё работает локально на твоём Mac — пароли и данные никуда не уходят.

## Установка

Нужен Mac (Apple Silicon или Intel, macOS 13+) и аккаунт МИРЭА. Открой **Терминал** и вставь:

```bash
zsh -c "$(curl -fsSL https://github.com/kostamirotvorec1-boop/mirea-hub-releases/releases/latest/download/install.sh)"
```

Установщик сам скачает всё нужное (права администратора не нужны), спросит логин и пароль
МИРЭА и почту, куда приходит код входа, и в конце покажет, как подключить iPhone.

Для автоматического кода из почты нужен **пароль приложения** (не обычный пароль от почты):
- Mail.ru: Настройки → Безопасность → Пароли для внешних приложений;
- Яндекс: Яндекс ID → Безопасность → Пароли приложений → «Почта»;
- Gmail: аккаунт Google → Безопасность → Пароли приложений.

## iPhone

iPhone и Mac должны быть в одной сети (домашний Wi‑Fi или Mac на раздаче с iPhone).
В Safari открой `http://<имя-твоего-мака>.local` — адрес покажет установщик — и следуй шагам.

## Обновление

MireaHub сам проверяет новые версии: Профиль → «О приложении» → «Обновить».
Или просто запусти команду установки ещё раз — данные сохранятся.

## Удаление

```bash
"$HOME/Library/Application Support/MireaHub/runtime/"*/bin/node "$HOME/Library/Application Support/MireaHub/app/current/server/src/agent.ts" uninstall
rm -rf "$HOME/Library/Application Support/MireaHub" "$HOME/Applications/MireaHub.app"
```
Пароли удаляются в приложении «Связка ключей»: поиск «MireaHub».
